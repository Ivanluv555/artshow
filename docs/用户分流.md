# Artshow用户注册与登录流程详解

## 📖 概述

Artshow系统支持多种用户类型，包括普通用户、商家、讲师和管理员。本文档详细阐述各类用户在注册和登录流程中的差异化设计。

---

## 🎭 用户类型架构

### 核心设计理念

**用户 (User) = 基础账户 + 身份 (Identity)**

```
User (基础账户)
├── isAdmin: Boolean (管理员标识)
├── Instructor (讲师身份) - 通过 user_id 关联
└── Merchant (商家身份) - 通过 user_id 关联
```

### 用户类型对照表

| 用户类型 | User表 | Instructor表 | Merchant表 | 说明 |
|---------|--------|-------------|-----------|------|
| 普通用户 | ✅ isAdmin=false | ❌ | ❌ | 仅有基础账户 |
| 讲师用户 | ✅ isAdmin=false | ✅ | ❌ | 基础账户 + 讲师身份 |
| 商家用户 | ✅ isAdmin=false | ❌ | ✅ | 基础账户 + 商家身份 |
| 多身份用户 | ✅ isAdmin=false | ✅ | ✅ | 基础账户 + 讲师 + 商家 |
| 管理员 | ✅ isAdmin=true | 可选 | 可选 | 拥有所有权限 |

## 📝 注册流程详解

### 1. 普通用户注册

#### API端点
```http
POST /user/register
Content-Type: application/json

{
  "userName": "zhangsan",
  "password": "password123",
  "nickName": "张三",
  "userAvatar": "http://example.com/avatar.jpg",
  "userBio": "艺术爱好者"
}
```

#### 处理流程

```java
// UserService.java - addUser()
@Override
public User addUser(UserDTO user) {
    // 1. 验证用户名唯一性
    if (user.getUserName() != null && !user.getUserName().isEmpty()) {
        User existingUser = userRepository.findByUserName(user.getUserName());
        if (existingUser != null) {
            throw new BizException(ResultCodes.INVALID_PARAM, "用户名已存在");
        }
    }

    User nUser = new User();
    BeanUtils.copyProperties(user, nUser);

    // 2. 加密密码（BCrypt）
    if (user.getPassword() != null && !user.getPassword().isEmpty()) {
        String encryptedPassword = PasswordUtils.encrypt(user.getPassword());
        nUser.setPassword(encryptedPassword);
    }

    // 3. 新注册用户默认为普通用户
    if (nUser.getIsAdmin() == null) {
        nUser.setIsAdmin(false);  // 关键：默认非管理员
    }
    
    return userRepository.save(nUser);
}
```

#### 数据库状态
```sql
-- user表
INSERT INTO user (user_id, user_name, password, nick_name, is_admin, created_at)
VALUES (123456789, 'zhangsan', '$2a$10$...', '张三', 0, NOW());

-- instructor表：无记录
-- merchant表：无记录
```

#### 响应
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "userId": 123456789,
    "userName": "zhangsan",
    "nickName": "张三",
    "isAdmin": false,
    "createdAt": "2026-07-28T10:00:00"
  }
}
```

### 2. 讲师用户注册

讲师用户采用**两步注册**流程：

#### 步骤1：注册普通用户账户
```http
POST /user/register
{
  "userName": "prof_li",
  "password": "password123",
  "nickName": "李教授"
}
```

#### 步骤2：申请讲师身份
```http
POST /instructor
Content-Type: application/json
Headers: Authorization: Bearer <JWT_TOKEN>

{
  "userId": 123456789,
  "title": "高级讲师",
  "specialization": "国画",
  "bio": "从事国画教学20年"
}
```

#### 处理流程

```java
// InstructorService.java - addInstructor()
@Override
public Instructor addInstructor(InstructorDTO instructorDTO) {
    if (instructorDTO == null) {
        throw new BizException(ResultCodes.NULLPOINT);
    }
    
    Instructor instructor = new Instructor();
    BeanUtils.copyProperties(instructorDTO, instructor);
    
    // 保存讲师身份信息
    return instructorRepository.save(instructor);
}
```

#### 数据库状态
```sql
-- user表
user_id: 123456789, is_admin: 0

-- instructor表（新增）
instructor_id: 987654321
user_id: 123456789
title: '高级讲师'
specialization: '国画'
status: 'pending'  -- 待审核
total_students: 0
total_courses: 0
```

#### 讲师审核流程
```
申请 (status='pending') 
  ↓ 
管理员审核
  ↓ 
通过 (status='active', approved_at=NOW())
  ↓
讲师可以创建课程
```

#### 步骤2：申请商家身份
```http
POST /merchant
Content-Type: application/json
Headers: Authorization: Bearer <JWT_TOKEN>

{
  "userId": 123456789,
  "shopName": "艺术精品店",
  "shopDescription": "专营传统手工艺品",
  "businessLicense": "营业执照编号123456"
}
```

#### 处理流程

```java
// MerchantService.java - createMerchant()
@Override
@Transactional
public Merchant createMerchant(Merchant merchant) {
    if (merchant == null) {
        throw new BizException(ResultCodes.NULLPOINT);
    }

    Long userId = merchant.getUserId();
    if (userId == null) {
        throw new BizException(ResultCodes.INVALID_PARAM, "用户ID不能为空");
    }

    // 检查用户是否已有商家身份（一个用户只能有一个商家身份）
    if (merchantRepository.existsByUserId(userId)) {
        throw new BizException(ResultCodes.INVALID_PARAM, "该用户已拥有商家身份");
    }

    // 设置默认值
    if (merchant.getStatus() == null) {
        merchant.setStatus("pending");  // 待审核
    }
    if (merchant.getTotalProducts() == null) {
        merchant.setTotalProducts(0);
    }

    return merchantRepository.save(merchant);
}
```

#### 数据库状态
```sql
-- user表
user_id: 123456789, is_admin: 0

-- merchant表（新增）
merchant_id: 456789123
user_id: 123456789
shop_name: '艺术精品店'
status: 'pending'  -- 待审核
total_products: 0
total_sales: 0.00
```

#### 商家审核流程
```
申请 (status='pending') 
  ↓ 
管理员审核营业执照
  ↓ 
通过 (status='active', approved_at=NOW())
  ↓
商家可以上架商品
```

### 4. 管理员注册

管理员**不能通过公开API注册**，必须通过以下方式创建：

#### 方式1：数据库直接插入（推荐）
```sql
-- 第一个管理员账户由数据库初始化脚本创建
INSERT INTO user (user_id, user_name, password, nick_name, is_admin, created_at)
VALUES (
    1, 
    'admin', 
    '$2a$10$...', -- BCrypt加密的密码
    '系统管理员', 
    1,  -- isAdmin = true
    NOW()
);
```

#### 方式2：由现有管理员创建（待实现）
```http
POST /admin/create-user
Headers: Authorization: Bearer <ADMIN_JWT_TOKEN>
Content-Type: application/json

{
  "userName": "admin2",
  "password": "admin123",
  "nickName": "管理员2",
  "isAdmin": true
}
```

⚠️ **安全考虑：**
- `isAdmin` 字段在普通注册接口中被强制设为 `false`
- 即使用户在请求中传入 `isAdmin: true`，也会被覆盖
- 只有通过特殊的管理员创建接口才能设置 `isAdmin: true`

## 🔐 登录流程详解

### 统一登录流程（所有用户类型）

所有用户类型使用**相同的登录接口**，无需区分身份。

#### API端点
```http
POST /user/login
Content-Type: application/json

{
  "userName": "zhangsan",
  "password": "password123"
}
```

#### 处理流程

```java
// UserService.java - login()
@Override
public String login(String username, String password) {
    if (username == null || password == null) {
        throw new BizException(ResultCodes.NULLPOINT);
    }
    
    // 1. 根据用户名查询用户
    User user = userRepository.findByUserName(username);
    if (user == null) {
        throw new BizException(ResultCodes.NOTFOUND, "用户名或密码错误");
    }

    // 2. 使用BCrypt验证密码
    if (!PasswordUtils.matches(password, user.getPassword())) {
        throw new BizException(ResultCodes.ERROR, "用户名或密码错误");
    }

    // 3. 生成JWT Token（包含userId和isAdmin）
    return JwtUtils.createToken(user.getUserId(), user.getIsAdmin());
}
```

#### JWT Token生成

```java
// JwtUtils.java - createToken()
public static String createToken(Long userId, Boolean isAdmin) {
    var builder = Jwts.builder()
            .subject(String.valueOf(userId))  // JWT的subject是userId
            .issuedAt(new Date())
            .expiration(new Date(System.currentTimeMillis() + EXPIRATION))
            .signWith(getKey());

    if (isAdmin != null) {
        builder.claim("isAdmin", isAdmin);  // 将isAdmin放入claims
    }

    return builder.compact();
}
```

#### JWT Token结构
```json
{
  "header": {
    "alg": "HS256",
    "typ": "JWT"
  },
  "payload": {
    "sub": "123456789",        // 用户ID
    "isAdmin": false,          // 是否管理员
    "iat": 1722153600,         // 签发时间
    "exp": 1722239999          // 过期时间（24小时后）
  },
  "signature": "..."
}
```

#### 响应
```json
{
  "code": 200,
  "message": "success",
  "data": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjM0NTY3ODkiLCJpc0FkbWluIjpmYWxzZSwiaWF0IjoxNzIyMTUzNjAwLCJleHAiOjE3MjIyMzk5OTl9.xxx"
}
```

## 🔍 身份验证与权限控制

### JWT Token解析

每个需要认证的请求都会经过 `AuthInterceptor` 拦截器：

```java
// AuthInterceptor.java - preHandle()
@Override
public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
    // 1. 提取JWT Token
    String token = request.getHeader("Authorization");
    if (token != null && token.startsWith("Bearer ")) {
        token = token.substring(7);
    }

    // 2. 解析Token
    io.jsonwebtoken.Claims claims = JwtUtils.parseClaims(token);
    Long userId = Long.parseLong(claims.getSubject());
    Boolean isAdmin = claims.get("isAdmin", Boolean.class);

    // 3. 存入ThreadLocal上下文
    UserContext.setUserId(userId);
    UserContext.setIsAdmin(isAdmin != null ? isAdmin : false);

    // 4. 检查角色权限（@RequireRole注解）
    if (handler instanceof HandlerMethod) {
        HandlerMethod handlerMethod = (HandlerMethod) handler;
        RequireRole requireRole = handlerMethod.getMethodAnnotation(RequireRole.class);
        
        if (requireRole != null) {
            UserRole[] requiredRoles = requireRole.value();
            boolean hasRequiredRole = UserContext.hasAnyRole(requiredRoles);

            if (!hasRequiredRole) {
                throw new BizException(ResultCodes.FORBIDDEN);
            }
        }
    }

    return true;
}
```

### UserContext上下文

```java
// UserContext.java
public class UserContext {
    private static final ThreadLocal<Long> userIdHolder = new ThreadLocal<>();
    private static final ThreadLocal<Boolean> isAdminHolder = new ThreadLocal<>();

    // 获取当前用户ID
    public static Long getUserId() {
        return userIdHolder.get();
    }

    // 获取当前用户是否为管理员
    public static Boolean getIsAdmin() {
        Boolean isAdmin = isAdminHolder.get();
        return isAdmin != null ? isAdmin : false;
    }

    // 检查是否为管理员
    public static boolean isAdmin() {
        return Boolean.TRUE.equals(isAdminHolder.get());
    }

    // 检查是否拥有指定角色
    public static boolean hasRole(UserRole role) {
        if (role == UserRole.ADMIN) {
            return isAdmin();
        }
        return true; // 普通用户角色
    }
}
```

### 4. 多身份用户权限

用户可以同时拥有讲师和商家身份：

```sql
-- user表
user_id: 123456789, is_admin: 0

-- instructor表
instructor_id: 987654321, user_id: 123456789

-- merchant表
merchant_id: 456789123, user_id: 123456789
```

**登录后拥有：**
- 普通用户所有权限
- 讲师所有权限（可以创建课程）
- 商家所有权限（可以上架商品）

**前端判断用户身份：**
```javascript
// 登录后查询用户的所有身份
async function getUserIdentities(userId) {
  const identities = {
    isInstructor: false,
    isMerchant: false,
    instructorId: null,
    merchantId: null
  };
  
  try {
    // 查询讲师身份
    const instructor = await fetch(`/instructor/by-user/${userId}`);
    if (instructor.ok) {
      identities.isInstructor = true;
      identities.instructorId = (await instructor.json()).data.instructorId;
    }
  } catch (e) {}
  
  try {
    // 查询商家身份
    const merchant = await fetch(`/merchant/by-user/${userId}`);
    if (merchant.ok) {
      identities.isMerchant = true;
      identities.merchantId = (await merchant.json()).data.merchantId;
    }
  } catch (e) {}
  
  return identities;
}
```

## 📊 完整流程图

### 注册流程对比

```
普通用户注册:
POST /user/register → User记录(isAdmin=0) → 完成

讲师用户注册:
POST /user/register → User记录(isAdmin=0)
  ↓
POST /instructor → Instructor记录(status='pending')
  ↓
管理员审核 → status='active' → 完成

商家用户注册:
POST /user/register → User记录(isAdmin=0)
  ↓
POST /merchant → Merchant记录(status='pending')
  ↓
管理员审核 → status='active' → 完成

管理员创建:
数据库直接插入 → User记录(isAdmin=1) → 完成
```

### 登录流程（统一）

```
所有用户类型:
POST /user/login
  ↓
验证用户名密码
  ↓
生成JWT(userId + isAdmin)
  ↓
返回Token
  ↓
客户端存储Token
  ↓
后续请求携带Token
  ↓
AuthInterceptor解析
  ↓
UserContext设置userId和isAdmin
  ↓
业务逻辑执行（根据身份查询权限）
```

## 🔒 安全措施

### 1. 密码安全
```java
// BCrypt加密，每次生成不同的盐值
String encrypted = PasswordUtils.encrypt("password123");
// 结果：$2a$10$N.zmdr9k7uOCQb6xNxr8p.G5lP7k9a...
```

### 2. JWT签名验证
```java
// 使用密钥签名，防止Token被篡改
SecretKey key = Keys.hmacShaKeyFor(jwtSecret.getBytes());
Jwts.builder().signWith(key).compact();
```

### 3. 权限隔离
```java
// 用户只能操作自己的资源
if (!resource.getUserId().equals(UserContext.getUserId())) {
    throw new BizException(ResultCodes.FORBIDDEN);
}
```

### 4. 身份审核
```java
// 讲师和商家必须经过管理员审核才能使用特权功能
```

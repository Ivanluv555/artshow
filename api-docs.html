Authentication & Authorization

This API uses JWT Bearer Token authentication with Role-Based Access Control (RBAC).

User Roles

  • USER: Regular users - Can browse, purchase, post, comment, like
  • INSTRUCTOR: Instructors - USER permissions + Create/manage courses and products
  • ADMIN: Administrators - Full system access including user management

How to Use

  1. Register: Call POST /user to create an account (default role: USER)
  2. Login: Call POST /user/login to get your JWT token (contains userId and role)
  3. Authorize: Click the 🔓 Authorize button in the top right corner
  4. Enter Token: Paste your JWT token (no need to add 'Bearer' prefix)
  5. Test APIs: All subsequent requests will automatically include your token

API Access Levels

  • 🌐 Public: No authentication required (marked with green lock)
  • 🔒 Login Required: Any authenticated user
  • 👨‍🏫 Instructor/Admin: INSTRUCTOR or ADMIN role required
  • 🛡️ Admin Only: ADMIN role required
